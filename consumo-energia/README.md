# Projeto consumo de energia - Aparelho: Geladeira - Cálculo do Consumo Mensal em kWh e cálculo do custo estimado

Projeto em linguagem Python contendo **Entrada -> Processamento -> Saída ***, usando a fórmula:
•consumoMensal = (potencia *horasDia* 30) / 1000

![Python](https://img.shields.io/badge/Python-3.9%2B-blue?logo=python&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-181717?logo=github&logoColor=white)
![Energy](https://img.shields.io/badge/Energy-Eficiente-green?logo=power)

O programa solicita o nome do aparelho, potência do aparelho em watts (W),  tempo médio de uso diário em horas e consumo mensal em KWh e mostra o consumo estimado kWh/mês.
